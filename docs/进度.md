- **为什么 21 而不是 17（2026-09-19 实测）**：`--release 17` 会把 **API 也锁到 17** —— `javac --release 17` 编 `Thread.ofVirtual()` 直接报"找不到符号"，`--release 21` 才通过（运行输出 `VirtualThread[...]`）。本项目 IO 密集（调 LLM / 调 Java 服务 / 等审批），**虚拟线程是真实技术卖点**，不能用 17 自断。
- 三者关系：**SDK = 用哪套 JDK；Language level + pom `java.version` = 允许用哪些语法与 API**。JDK 21 能编 17 的代码，反之不行。真源是 **pom**，IDE 级别只影响标红提示。
